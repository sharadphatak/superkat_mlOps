## Interpretation and limits

MRP has the largest impurity-based feature importance (approximately 44.95%), followed by weight (10.03%). Store characteristics and identity also matter. These values describe this fitted model, are not causal conclusions, and can favor features with many possible values.

The larger RMSE relative to MAE suggests some comparatively large errors; inspect `reports/holdout_predictions.csv` and the residual figure before relying on estimates for decisions. The random holdout covers the observed product/store distribution, not future periods or genuinely new stores. Only four stores are present. No timestamps exist to establish weekly/monthly/quarterly/annual forecast accuracy.

**Not tested:** authenticated Google Colab execution, real GitHub Actions runs/branch permissions, Docker builds, Streamlit Community Cloud or public Hugging Face deployments. No live deployment evidence is claimed. The included notebook remains ready-to-run Colab source; it is not a final academic HTML submission.
